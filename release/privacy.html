Autofill Privacy Policy

This policy describes how the Autofill browser extension handles information to help you fill forms.

Information used by the extension

The extension uses profile details and answers you save, form labels and control metadata, and website origins associated with permissions, exclusions or saved answers. On authorized pages, it uses this information to match empty fields. With learning enabled, eligible completed answers can appear in a temporary review queue. You can also start a review manually for eligible fields you edited on the current page. An answer is added to the vault when you approve it.

Storage and security

Your profile and approved answers are encrypted in Chrome's local extension storage using AES-GCM. While unlocked, the derived key is available in trusted Chrome extension session storage. You can hide saved details in the dashboard while form filling stays available for the current browser session. Your passphrase is used to derive the key and is not stored. Site preferences are stored locally. JSON exports contain readable data and should be kept somewhere you trust.

Sharing and website access

Autofill has no developer-operated backend, analytics, advertising or data sales. If the extension fills a value on an authorized page, that website can read the value in its form. The extension does not submit forms. You control which websites it can access and can revoke that access in the extension or through Chrome.

Control and deletion

You can disable learning, delete individual answers, or use Clear saved information to remove the vault and preferences. Removing the extension clears its local extension storage. Exported backups stay wherever you saved them and can be deleted there.

Limited use and contact

The use of information received from Google APIs will adhere to the Chrome Web Store User Data Policy, including the Limited Use requirements. For privacy questions, use the support contact on the Autofill Chrome Web Store listing.
